## 8. 建议

1. 修复 sandbox 启动与 tools 依赖的初始化等待，避免插件进程死锁。
2. 插件停止后从 bootstrap 与 UI 中移除挂载，或明确标注不可用。
3. 修正 subagent 的 Custom Element 名，并补 UI 注册测试。
4. 子会话行过滤空值，避免渲染 `null`。
5. 刷新恢复时清理草稿策略需明确；若要求保留，应进持久化。
6. Host 重启后自动重同步 Facts，并把 `Failed to fetch` 换成可读提示。
7. 用多进程客户端复测 L-C2，区分 Host 与客户端解析瓶颈。
8. 为日志增加轮转与采样开关，避免压测时日志失真。
