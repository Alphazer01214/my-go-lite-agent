    01

    Frame 字段解剖

    线格式是 4 字节大端长度加 UTF-8 JSON body，单条上限 16 MiB。下面每一行都注明谁写、何时写。

    02

    pending 键与 id 的关系

    这是最容易搞错的地方：pending 的键不是插件的 id，是 Host 自己分配的内部 id。

    归因事件与 Response 走同一条还原路径：Host 查 pending，把 Frame.id 换回发起方的原始 id，再投回去。
